# Prototipo Agente WhatsApp — Salteñas El Conejo (V6)

Prototipo estático e interactivo listo para GitHub y Vercel.

## Corrección móvil V6

- En teléfonos reales ya no se muestra un iPhone artificial dentro del iPhone.
- El chat ocupa únicamente el viewport visible de Safari/Chrome.
- Encabezado y campo de escritura permanecen visibles.
- Solo se desplaza el historial de mensajes.
- Cada respuesta nueva lleva la conversación al último mensaje.
- El usuario puede deslizar hacia arriba dentro del chat para leer el historial.
- El teclado móvil redimensiona el área útil sin desplazar toda la página.
- Se conservan todas las respuestas y flujos del agente.

## Archivos

- `index.html`: aplicación completa, autocontenida.
- `.nojekyll`: compatibilidad con GitHub Pages.
- `README.md`: descripción del proyecto.
- `DEPLOY.md`: actualización y despliegue.

## Nota

La demo no está conectada al WhatsApp oficial, Ferialive, la cocina ni Mercado Pago. Simula el comportamiento de la futura implementación.
